# Assets

This directory stores reusable fonts, images, music, and sound effects, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Store reusable font files and generated font sources in `fonts/`.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

### Korean learner font subsets

`fonts/ko_*.c` are LVGL 9.5 bitmap fonts generated by
[`tools/gen_korean_assets.py`](../tools/gen_korean_assets.py) with `lv_font_conv`
1.5.3 (`--no-compress --no-kerning`). Each character set is derived exactly from
[`korean/content.json`](korean/content.json) and recorded, with the full command
and source-font hashes, in [`fonts/ko_fonts.manifest.json`](fonts/ko_fonts.manifest.json).
`main/CMakeLists.txt` compiles every `ko_*.c`; the static gate re-reads their
character maps and fails when they no longer match the content.

| File | Size / bpp | Glyphs | Source font | Draws |
| --- | --- | ---: | --- | --- |
| `ko_zh14.c` | 14 px / 4 | 575 | Source Han Sans SC Regular | Small Chinese text, romanization, key hints |
| `ko_zh20.c` | 20 px / 4 | 575 | Source Han Sans SC Regular | Titles, meanings, quiz options |
| `ko_ko24.c` | 24 px / 4 | 398 | Source Han Sans KR Regular | All Korean text, emblems |
| `ko_ko32.c` | 32 px / 4 | 324 | Source Han Sans KR Regular | Words and phrases |
| `ko_ko48.c` | 48 px / 2 | 330 | Source Han Sans KR Regular | Word cards, quiz prompts, scores |
| `ko_jamo96.c` | 96 px / 2 | 40 | Source Han Sans KR Regular | Letter-card glyphs |

Sources: [Adobe Source Han Sans](https://github.com/adobe-fonts/source-han-sans)
2.005 `SubsetOTF/SC` and `SubsetOTF/KR`, licensed under the SIL Open Font License
1.1, which permits redistributing these derived subsets. The source `.otf`
files are not committed; the manifest records their SHA-256 values.

## Images

Store reusable source images and generated display assets in `images/`.

| File | Dimensions and format | Use and source |

- Use descriptive names and document dimensions, pixel format, conversion steps, and destination.
- Prefer formats suitable for the 240 × 320 RGB565 display and account for Flash and internal RAM.
- Preserve editable sources where licensing permits, and record the source and license.
- Never commit device QR secrets, credentials, or personal data in images.

## Korean learner content

[`korean/content.json`](korean/content.json) is the single source of every
string the Korean learner displays: letters, vocabulary, phrases and interface
text. Romanization follows the Revised Romanization of Korean. Append new items
at the end of a list so saved progress stays aligned, then rerun
`tools/gen_korean_assets.py`. The content was written for this repository.

## Music and sound effects

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.

The Korean learner's pronunciation pack is generated locally into
`audio/generated/kopack.bin` by [`tools/korean_audio.py`](../tools/korean_audio.py)
from Microsoft Edge online text-to-speech (16 kHz mono, 4-bit IMA-ADPCM). Its
redistribution terms are not confirmed, so the directory is ignored by Git.
